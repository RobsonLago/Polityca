# Política de Privacidade — Gustinha CSGOnet

Última atualização: 24 de agosto de 2026

A extensão **Gustinha CSGOnet** (“a extensão”) foi criada para uso exclusivo no site **csgo.net**, com dois objetivos:

1. Aplicar automaticamente o cupom de desconto **GUSTINHA**.
2. Exibir, em tempo real, os resultados (*rolls*) do sistema **Provably Fair** durante upgrades de skins, capturados diretamente do WebSocket que o próprio site já utiliza para se comunicar com o servidor.

## Quais dados a extensão acessa

- **Conteúdo da página do csgo.net**: preço da caixa/upgrade, nome dos itens e elementos visuais necessários para inserir o cupom e exibir os resultados.
- **Mensagens do WebSocket do site**: usadas apenas para ler os resultados (rolls) do sistema Provably Fair já fornecido publicamente pelo site.

## O que a extensão NÃO faz

- Não coleta nome, e-mail, senha ou qualquer dado de identificação pessoal.
- Não coleta dados financeiros, de saúde, de localização ou histórico de navegação.
- Não registra teclas digitadas, cliques ou atividade do usuário fora do necessário para seu único propósito.
- Não envia nenhum dado para servidores próprios, de terceiros ou para fins de publicidade.
- Não vende, aluga ou compartilha dados com terceiros.
- Não usa os dados para fins diferentes dos descritos acima, nem para avaliação de crédito ou concessão de empréstimos.

## Armazenamento

Todos os dados são processados **localmente, no navegador do usuário**, apenas durante a sessão de navegação, e não são persistidos após o fechamento da aba ou do navegador.

## Permissões solicitadas

- **Acesso ao domínio `csgo.net`**: necessário para que a extensão funcione, já que todo o seu propósito depende de ler e interagir com o conteúdo desse site específico. Nenhum outro domínio é acessado.
